Display

Artboard measures from the top left with Y running down, matching the Transform panel. Document uses raw ruler coordinates.

Extend path

Continue an open path along its own direction. Works on every selected open path at once.

Bezier pushes the end segment's own curve further, adding no anchor. Arc continues at the curvature the path already has. Spiral starts at that curvature and opens out. Trim removes the same length from the same end, in any mode.

Tangent from a path

Strike a line tangent to the path at a selected anchor. Locked, it follows when the path is edited.

0 strikes at the anchor itself. Anything up to 1 walks that fraction of the way along the segment after it, by arc length, so you can strike anywhere on a curve. For tangents between two circles, see the Tangency tab.

Connect circles

Select two circles. Chisel finds their common tangents, builds the geometry, and locks it to both. Move or scale either circle afterwards and it rebuilds itself.

Belt gives one closed outline wrapping both circles: a pulley, a capsule, a chain link. Side only applies to a single tangent.

Tangent circle

A new circle of a chosen radius touching both selected circles, locked to them.

Tangent from a point

Select a circle, plus one path with a single anchor selected. The tangent stays attached to that anchor as it moves.

Tangent continuity

Forces the two handles at an anchor to stay collinear, so a curve you drew smooth stays smooth through every later edit.

Weld

Holds an anchor on one path to an anchor on another. Select two paths with one anchor selected on each; the first leads.

Sync

Illustrator tells extensions nothing about edits as they happen, so Chisel watches for movement and rebuilds. Each rebuild is one undo step. Turn this off while working on something unrelated.
